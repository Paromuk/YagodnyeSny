# Ягодные сны

«Ягодные сны» — это веб-приложение для ягодной фермы. Сайт предоставляет информацию о ферме, её продукции, актуальных вакансиях и контактных данных для продаж и сотрудничества.

## Реализованная функциональность

- **Информационные страницы:** Предоставляет статический контент для страниц «О ферме», «Вакансии» и «Контакты».
- **Модульная система шаблонов:** Использует базовый макет (`layout.html`) для управления заголовком и подвалом сайта с динамической вставкой контента для разных страниц.
- **Обслуживание статического контента:** Обрабатывает и отдаёт CSS, JavaScript и изображения для фронтенда.

## Особенность проекта

- **Полностью адаптивный дизайн:** Сайт построен с использованием CSS Flexbox и Grid, что гарантирует оптимальное отображение на всех устройствах: от смартфонов до настольных компьютеров.
- **Интерактивные карточки:** Контент представлен в виде современных визуально привлекательных карточек с эффектами при наведении, что делает навигацию интуитивно понятной и интересной.
- **Динамическая навигация:** Панель навигации автоматически подсвечивает текущую страницу (`active_page`), обеспечивая чёткую визуальную обратную связь для пользователя.

## Основной стек технологий

- **Бэкенд:** Python 3, Bottle (WSGI микро-фреймворк)
- **Фронтенд:** HTML5, CSS3 (Flexbox, Grid, CSS переменные)
- **Стилизация:** Пользовательский CSS (без использования внешних CSS-фреймворков для основной сетки)
- **JavaScript:** jQuery, Bootstrap JS (для навигации и интерактивных компонентов)
- **Сервер:** WSGIReference (встроенный сервер разработки Bottle)

## Среда запуска

- Сервис разработан и протестирован на **Windows**, **macOS** и **Linux** (Debian-подобных).
- Требуется установленный **Python 3.6+**.
- Для базовой функциональности не требуется внешняя база данных или веб-сервер (например, Apache/Nginx).

## Установка

### 1. Установите Python
Убедитесь, что на вашей системе установлен Python версии 3.6 или выше. Вы можете скачать его с [официального сайта](https://www.python.org/downloads/).

### 2. Клонируйте репозиторий
git clone <url-вашего-репозитория>
cd <папка-проекта>

### 3. Установите зависимости
Проект использует Bottle, который можно установить через pip:
pip install bottle

### Запуск приложения
Перейдите в корневую директорию проекта в терминале и запустите Python-приложение:
python app.py
